# Subroutines Observed In Interactive Traces

Primary evidence is the quine trace generated by:

```sh
tools/run-dispak.sh --bootstrap -t -t poplan.b6 \
    < quine.pop2 > output 2> trace.quine
```

Regenerate its dynamic call inventory with:

```sh
tools/analyze-trace.py trace.quine
```

Descriptions below also use short interactive startup/exit traces. Batch mode
adds only the greeting and immediate exit and is not part of the analysis.
All claims are dynamic unless a static instruction sequence is explicitly
identified.

The normal link register is `r15`. The only direct target called with `r14` in
the quine trace is `11673`.
