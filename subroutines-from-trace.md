# Subroutines Observed In Interactive Traces

Primary evidence is the quine trace generated by:

```sh
tools/run-dispak.sh --bootstrap -t -t poplan.b6 \
    < quine.pop2 > output 2> trace.quine
```

Regenerate its dynamic call inventory with:

```sh
tools/analyze-trace.py trace.quine
```

Descriptions below also use short interactive startup/exit traces. Batch mode
adds only the greeting and immediate exit and is not part of the analysis.
All claims are dynamic unless a static instruction sequence is explicitly
identified.

The normal link register is `r15`. The only direct target called with `r14` in
the quine trace is `11673`.

## Dynamic Inventory

The quine has 98 direct `vjm` targets. Nineteen currently have semantic
descriptions above; the generated inventory in `build/calls.md` is the
authoritative count/caller table.

The highest-frequency unnamed targets are `11541`, `11673`, `16457`, `21275`,
`25346`, `11717`, `16421`, `05430`, and `05447`. These are the next useful
targets for trace-guided analysis.

"Leaf" in generated output means no nested `vjm` was observed while a traced
invocation was active. It is not proof that the routine is leaf for every
input. The analyzer recognizes normal register returns and the
`utc (link)` computed-return idiom used by `20110`.
